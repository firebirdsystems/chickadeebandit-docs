# Family Documents

A [Chickadee Bandit](http://chickadeebandit.com) app.

Store and share family documents — receipts, medical records, school papers, insurance policies. Organise into folders with adult-only or family-wide visibility.

## Features

- Upload PDFs, images (JPEG, PNG, HEIC, WebP), Word, Excel, and text files
- Inline preview for images and PDFs
- Folder organisation with per-folder visibility (everyone / adults only)
- Up to 10 MB per file, 500 MB total storage

## Install

In your hub, go to **Apps → Install from URL** and paste:

```
https://github.com/firebirdsystems/chickadeebandit-docs/releases/latest/download/bundle.json
```
